BugVault

BugVault is a web-based Bug Tracking System designed to streamline the software testing and debugging workflow. It enables teams to efficiently report, track, manage, and resolve bugs throughout the software development lifecycle.

The system supports multiple user roles:

Tester – Reports bugs, monitors their status, and verifies fixes.
Developer – Views assigned bugs, updates progress, and resolves issues.
Manager – Oversees project activities, assigns tasks, and tracks team performance.
Key Features
Role-based authentication and access control.
Bug reporting and issue tracking.
Bug status management (Open, In Progress, Resolved, Closed).
Assignment of bugs to developers.
Dashboard for monitoring bug progress.
Centralized bug history and records.
Purpose

BugVault helps development teams maintain software quality by providing a structured platform for bug management, improving collaboration between testers, developers, and managers, and ensuring timely issue resolution.
